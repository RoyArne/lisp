
# The Unicode Character Database

The "unicode-character-database" system is used to read files from the
Unicode Character Database.

## unicode-character-database.asd

System definition.

## unicode-character-database.lisp

Package definition. We export the most important functionality from
here. The other packages uses this package and will define the actual
functions.

- make-unicode-character-database-pathname—configuration.lisp
- read-database-stream—parser.lisp
- load-database-file—parser.lisp
- write-unicodedata-tables—unicodedata.lisp
- write-proplist-tables—proplist.lisp
- write-common-lisp-tables—common-lisp-standard-characters.lisp

## configuration.lisp

- (**make-unicode-character-database-pathname** _filename_) → _pathname_

  Returns the pathname to _filename_ in the
  unicode-character-database/data/UCD/ directory.

## parser.lisp

Basic parser for the files in the Unicode Character Database. It takes
care of the code point field and leaves the remaining fields as
strings. It also strips comments.

- (**read-database-stream** _stream_) → _list_
- (**read-database-file** _filename_) → _list_

  _filename_ must be a file in the Unicode Character Database, see
  configuration.lisp for specific location.

- (**with-nth-field** (_field_ _n_ _line_) &body _body_)

  Evaluate body with the _n_ th field of _line_ bound to the _field_
  variable.

- (**when-nth-field** (_field_ _n_ _line_) &body _body_)

  Bind the _n_ th field of _line_ to the _field_ variable as with
  **with-nth_field**, but only evaluate _body_ if _field_ is longer
  than zero characters.

- (**with-nth-fields** _list_ (&rest _fields_) &body _body_)

  Given a _list_ of fields and zero or more _fields_ in the form
  (_name_ _n_) evaluate _body_ with the _n_ th field(s) bound to the
  _name_ variable(s).

## unicodedata.lisp

Parser for "unicodedata.txt".

- (**write-unicodedata-tables**) → t

  Writes the following tables to the directory
  unicode/data/unicodedata/:

- character-names
- general-category
- canonical-combining-classes
- bidirectional-category
- ~~canonical-decomposition-mapping~~—not defined yet.
- ~~compatibility-decomposition-mapping~~—not defined yet.
- decimal-digit-value
- digit-value
- numeric-value
- mirrored
- uppercase-mapping
- lowercase-mapping
- titlecase-mapping

The tables are readable and generated by means of the #:unicode.table
package.

## proplist.lisp

Parser for "PropList.txt". Writes tables for the properties in
[PropList.txt](https://www.unicode.org/reports/tr44/#PropList.txt) to
the directory unicode/data/proplist/.

- (**write-proplist-tables**) → t

## common-lisp-standard-characters.lisp

Adds tables for the standard Common Lisp characters defined in [2.1.3
Standard
Characters](https://www.lispworks.com/documentation/HyperSpec/Body/02_ac.htm),
[2.1.4 Character Syntax
Types](https://www.lispworks.com/documentation/HyperSpec/Body/02_ad.htm),
and [2.1.4.2 Constituent
Traits](https://www.lispworks.com/documentation/HyperSpec/Body/02_adb.htm)
in the Common Lisp HyperSpec.

- (**write-common-lisp-tables**) → t
