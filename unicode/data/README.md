
# Unicode/Data

This directory contains data files generated by the
"unicode-character-database" system.

## unicodedata.txt

The following files are generated from "unicodedata.txt" in the
Unicode Character Database. The generator is the
"UNICODE-CHARACTER-DATABASE.UNICODEDATA" package, which employs
"UNICODE.TABLE" to **create unicode.table:property-map**,
**unicode.table:code-point-map**, **unicode.table:property-table** and
**unicode.table:string-map** structures.

- bidirectional-category.lisp
- canonical-combining-classes.lisp
- character-names.lisp
- decimal-digit-value.lisp
- digit-value.lisp
- general-category.lisp—a **property-map**.

  Maps code points to the keywords :LU (Letter Uppercase), :LL
  (Lowercase), :LT (Titlecase), :LM (Modifier), :LO (Other), :MN (Mark
  Non-Spaciong), :MC (spacing-Combining), :ME (Enclosing), :ND (Number
  Decimal digit), :NL (Letter), :NO (Other), :PC (Punctuation
  Connector), :PD (Dash), :PS (open), :PE (close), :PI (Initial
  quote), :PF (Final quote), :PO (Other), :SM (Symbol Math), :SC
  (Currency), :SK (modifier), :SO (Other), :ZS (separator Space), :ZL
  (Line), :ZP (Paragraph), :CC (other Control), :CF (Format), :CS
  (Surrogate), :CO (private use), and :CN (Not assigned).
  
- lowercase-mapping.lisp
- mirrored.lisp
- numeric-value.lisp
- titlecase-mapping.lisp
- uppercase-mapping.lisp
