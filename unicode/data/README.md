
# The Unicode "data/" Directory

The "data/" directory mirrors the layout of the [Unicode Character
Database](https://www.unicode.org/Public/UCD/latest/) (UCD). However,
the data files like "UDC/UnicodeData.txt" have been replaced by
directories containing a number of tables (one table per file).

For example, the above mentioned "data/UDC/UnicodeData.txt" is instead
a directory "data/UDC/UnicodeData/" containing the files
"bidirectional-category.lisp" and "decimal-digit-value.lisp" among
others.

We also have our own additions, like the "data/Common-Lisp" directory,
which mimics the layout of the UCD files.
